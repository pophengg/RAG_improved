# การแบ่งเอกสาร
## Token chunking
Token chunking แบ่งข้อความตามจำนวน token ของ tokenizer แทนการนับช่องว่าง เหมาะกับข้อความภาษาไทยที่ไม่ได้เว้นวรรคทุกคำ รุ่นปรับปรุงตั้งขนาด 384 token และ overlap 64 token เพื่อรักษาข้อมูลตรงรอยต่อ
## โครงสร้าง Markdown
หัวข้อ Markdown ช่วยระบุว่าเนื้อหาอยู่ในส่วนใด การเก็บเส้นทางหัวข้อไว้ใน metadata ช่วยค้นหา chunk ที่มีข้อความสั้นแต่ต้องอาศัยบริบท
