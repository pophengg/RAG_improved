# การสร้างเวกเตอร์
## BGE-M3
ระบบทั้งสองใช้ BAAI/bge-m3 สร้าง dense embedding สำหรับค้นหาความหมาย การใช้ batch ช่วยลด overhead และ normalization ทำให้เวกเตอร์มีความยาวหนึ่ง โดยไม่ได้เปลี่ยนโมเดลที่สร้างคำตอบ
## บริบท
Contextual embedding รวมเนื้อหา chunk กับบริบทสั้นจากเอกสารเต็ม เพื่อช่วยแยกข้อความที่ใช้คำคล้ายกันแต่หมายถึงคนละเรื่อง
