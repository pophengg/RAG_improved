# การค้นหา
## BM25
BM25 เป็นการค้นหาจากคำ ใช้ความถี่คำและความยาวเอกสาร ภาษาไทยควรใช้ analyzer ที่แบ่งคำภาษาไทยได้
## Hybrid และ RRF
Hybrid search รวมผลค้นหาจาก BM25 และ dense vector ด้วย Reciprocal Rank Fusion หรือ RRF คะแนนของรุ่นปรับปรุงเท่ากับผลรวม weight หารด้วย 60 บวกอันดับ โดยอันดับแรกเริ่มที่หนึ่ง ไม่จำเป็นต้องปรับคะแนนดิบ BM25 ให้เท่ากับ cosine similarity
